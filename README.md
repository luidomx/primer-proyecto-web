# Mi primer proyecto web

Este proyecto fue realizado como parte de una tarea de la carrera de Ingeniería en Software.

El objetivo de la actividad es poner en práctica algunos conceptos básicos de desarrollo web, utilizando HTML, CSS y TypeScript.

## Tecnologías utilizadas

- HTML para la estructura de la página.
- CSS para los estilos.
- TypeScript para la programación.

## Archivos del proyecto

- `index.html`: estructura principal de la página.
- `style.css`: estilos de la página.
- `script.ts`: código TypeScript.
- `script.js`: archivo JavaScript generado al compilar.

## Ejecución

Para compilar el archivo TypeScript:

```bash
tsc script.ts
